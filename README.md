# NoGa OS — downloads and website

NoGa OS is a desktop-style app focused on helping kids learn real computer basics in a controlled space: mouse, keyboard, windows, files, and simple educational/play apps. It is intentionally not a real operating system.

**[nogaos website](https://celtric.github.io/nogaos-site/)** · **[download the latest version](https://github.com/celtric/nogaos-site/releases/latest)**

Run it with `java -jar nogaos-<version>.jar` on Java 17 or newer. It works on Linux, Windows, macOS and Raspberry Pi.

## What this repository is

Only the website and the downloadable builds. The source code is not public at the moment, so there is nothing to clone here — the `gh-pages` branch is generated and replaced on every release.

## Feedback

Bug reports, questions and comments are welcome in [Issues](https://github.com/celtric/nogaos-site/issues). It is an early personal project built for my own children, so expect rough edges.
