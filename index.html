NoGa OS

NoGa OS is a virtual operating system for kids: a complete desktop with its own windows, files and apps, running as a single Java program on any computer. It helps kids learn real computer basics in a controlled space: mouse, keyboard, windows, files, and simple educational/play apps. It is intentionally not a real operating system: the host does the low-level work, so all the effort goes into what a kid actually sees and touches. And it is a gateway rather than a destination: a kid outgrows it in a few years and moves on to Windows, macOS or Linux, so NoGa OS keeps to the habits those desktops share, made bigger, fewer and plainer, instead of inventing its own.

Running it

Install Java 17 or newer, then run the downloaded file:

java -jar nogaos-174.jar

The first start asks you to create an account. Video and audio playback need VLC installed on the computer; nothing else does.

A computer of their own

An old laptop or a Raspberry Pi can become a NoGa OS computer: it powers on straight into NoGa OS, with no login prompt and no Linux desktop reachable behind it. Install Debian (the small "netinst" image, with no desktop environment selected) or Raspberry Pi OS Lite, log in, and run:

wget -qO install-kiosk.sh https://celtric.github.io/nogaos-site/install-kiosk.sh && sudo bash install-kiosk.sh

It installs Java and everything else NoGa OS needs, downloads the latest version and sets the computer to start it on boot. It is a plain script you can read first, and running it again is safe.

Status

This is a personal project, written for my own children and shared in case it is useful to anyone else. It is early and it has rough edges. If you try it, bug reports and comments are welcome.

Changelog

Version 174 · 25 September 2026

  • The **Users** applet's forms no longer close on a missing name or password and complain afterwards: **OK** stays greyed out until the fields are filled, and a name another user already has is refused while the form stays open with what was typed
  • The toolbars wear the classic explorer icons of the late nineties instead of the Tango set: the File Explorer, the Open and Save dialogs, the Internet Browser, the PDF Viewer and Paint's undo and redo, with the Media Player's play, pause, stop and seek buttons from the Media Player of the same era
  • In the setup wizards, **Back** and **Next** sit together as one group of buttons

Version 172 · 24 September 2026

  • The **Italian** app becomes **Languages**: the same picture cards and quiz, now in Italian and in English, read by the computer's voices. It replaces English Words, and the Drums app is gone too
  • Voices are managed from a new **Voices** tab in the Sounds settings, where a grown-up installs, removes, picks and tries the voices for Catalan, English and Italian; an app that needs a missing voice now points there instead of asking to download it
  • Dragging a Control Panel applet onto the desktop or into a folder makes a shortcut to it

Version 171 · 24 September 2026

  • New **PDF Viewer** app: every page on one scrolling strip with small pages beside it to jump to, zoom in the corner of the status bar, and printing. PDF files open there now instead of in the browser
  • New **Drums** app: a drum set seen from the drummer's seat to hit with the mouse or the keyboard, and a beat grid to make rhythms with
  • New **English Words** app: a word in Catalan and then in English, one after another in the background, run from its icon next to the clock. The first app to talk asks a grown-up to download the computer's voices, which any app can then use to read aloud
  • Internet Browser: find in page (Ctrl+F), zoom in round steps from the corner of the status bar, a Downloads button on the toolbar, and folders on the bookmarks bar
  • Media Player rebuilt: one bar of controls under the picture, a "now playing" line instead of a black square for a sound file, and a real fullscreen for videos that hides the taskbar too (Escape brings it back); the browser's video fullscreen does the same
  • Desktop polish: pictures open in the picture viewer with Paint under **Open with**, a long file name breaks across its two lines instead of ending in dots, the network icon next to the clock is crossed while the computer is off the network, and Notepad no longer freezes when pointed at a PDF
