NoGa OS

NoGa OS is a virtual operating system for kids: a complete desktop with its own windows, files and apps. It helps kids learn real computer basics in a controlled space: mouse, keyboard, windows, files, and simple educational/play apps. It is intentionally not a real operating system: the host does the low-level work, so all the effort goes into what a kid actually sees and touches. And it is a gateway rather than a destination: a kid outgrows it in a few years and moves on to Windows, macOS or Linux, so NoGa OS keeps to the habits those desktops share, made bigger, fewer and plainer, instead of inventing its own.

Running it

Install Java 17 or newer, then run the downloaded file:

java -jar nogaos-202.jar

The first start asks you to create an account. Video and audio playback need VLC installed on the computer; nothing else does.

A computer of their own

An old laptop or a Raspberry Pi can become a NoGa OS computer: it powers on straight into NoGa OS, with no login prompt and no Linux desktop reachable behind it. Install Debian (the small "netinst" image, with no desktop environment selected) or Raspberry Pi OS Lite, log in, and run:

wget -qO install-kiosk.sh https://celtric.github.io/nogaos-site/install-kiosk.sh && sudo bash install-kiosk.sh

It installs Java and everything else NoGa OS needs, downloads the latest version and sets the computer to start it on boot. It is a plain script you can read first, and running it again is safe.

Status

This is a personal project, written for my own children and shared in case it is useful to anyone else. It is early and it has rough edges. If you try it, bug reports and comments are welcome.

Version 201 · 13 October 2026

  • **Worksheets**: marks beside the page number show which pages were got right, with a summary on the last page (nothing is kept once the worksheet is closed), and the arrow to the next page waits for the answer; pages no longer show their kind's pictogram and name, and the cheer has the top of the page to itself, covering nothing; a worksheet can be written in the joined-up school hand Betània Patmos, in capitals or as written, and its author can record her own "Well done!"; pictures can be built from a value (a clock from its time, coins from an amount, a fraction, a ruler, a calendar and more); every right answer is cheered the same way, **Picture parts** plays one way only, and the hidden explanations of Reading and True or false are gone
  • **Shape Editor**: right-click a zone in the list to rename or delete it

Version 200 · 13 October 2026

  • **Worksheets**: twelve new kinds of page in the **Words** tab: reading comprehension, fill the gap, true or false, odd one out, rhymes, syllables, sort them, in order, puzzle, word search, crossword (reading comprehension and true or false can explain the answer once it is right) and **Picture parts**, where the kid finds or labels the parts of a picture marked in the new Shape Editor; a right answer shows a band over the page's heading with the cheer and a strip that fills before the page turns, and pages no longer read their heading aloud as they show; Pairs and Memory, and the three listen-and-choose pages, are now one kind each with modes the editor switches between from a row above the page, and the speaker under a word in the editor shows whether a recording or the computer's voice will be heard and changes it on click
  • **New Shape Editor app**: marks the parts of a picture, boxes, ellipses and polygons each with a name, or names the shapes an SVG drawing such as a map already has, with wheel zoom for small pictures, and saves a `.forma` file the Worksheet Editor turns into a Picture parts page
  • **Paint**: the toolbox shows the classic Windows 95 Paint icons again instead of a preview of each tool's stroke
  • **Voice Recorder**: one bar does it all: while you record, the take draws its sound as it grows, red where it was too loud; once stopped, the same bar plays it back like the Media Player's, with **Play** turning into **Pause**, **Space** and **Enter** pressing it too, and a click on the bar jumping there
  • **Media Player**: the progress bar shows the shape of the sound, so you can see where a song or a recording is loud, quiet or silent before you play it, the playhead glides instead of stepping once a second, and there is one play/pause button and no **Stop** (**Space** pauses too; click the start of the bar to go back to the beginning)
