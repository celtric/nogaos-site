NoGaOS

Smooth a child's way into computers.

"If you wish to make an apple pie from scratch, you must first invent the universe." — Carl Sagan

For a child to open a simple app and draw, there must first be a desktop, and everything around it that makes it safe and whole. NoGaOS is that universe, built so the pie is the easy part.

NoGaOS is a virtual operating system for kids: a complete desktop with its own windows, files and apps. It helps kids learn real computer basics in a controlled space: mouse, keyboard, windows, files, and simple educational/play apps. It is intentionally not a real operating system: the host does the low-level work, so all the effort goes into what a kid actually sees and touches. And it is a gateway rather than a destination: a kid outgrows it in a few years and moves on to Windows, macOS or Linux, so NoGaOS keeps to the habits those desktops share, made bigger, fewer and plainer, instead of inventing its own.

Running it

Install Java 17 or newer, then run the downloaded file:

java -jar nogaos-219.jar

The first start asks you to create an account. Video and audio playback need VLC installed on the computer; nothing else does.

A computer of their own

An old laptop or a Raspberry Pi can become a NoGaOS computer: it powers on straight into NoGaOS, with no login prompt and no Linux desktop reachable behind it. Install Debian (the small "netinst" image, with no desktop environment selected) or Raspberry Pi OS Lite, log in, and run:

wget -qO install-kiosk.sh https://celtric.github.io/nogaos-site/install-kiosk.sh && sudo bash install-kiosk.sh

It installs Java and everything else NoGaOS needs, downloads the latest version and sets the computer to start it on boot. It is a plain script you can read first, and running it again is safe.

Status

This is a personal project, written for my own children and shared in case it is useful to anyone else. It is early and it has rough edges. If you try it, bug reports and comments are welcome.

Changelog

Version 218 · 30 October 2026

  • The Log Viewer has a Processes tab listing each running part of the system (the battery warning, the sleep timer, each USB stick's mounting) with the state it is in and what it handled, and its log lines now name the part of the system at work and what it was doing instead of the class that wrote them.

Version 217 · 30 October 2026

  • Logging in is much quicker, most of all on a Raspberry Pi: the apps are prepared once, while the login screen is showing, instead of at every login.

Version 216 · 30 October 2026

  • The battery icon tells the kid when the battery drops below 10 %, once, and again only after the charger has been plugged in.
  • USB sticks and SD cards are ready as soon as they are plugged in, even before anyone logs in, and their drive appears at once when someone does.
  • With two people logged in at once, a change one of them makes to the users, app permissions, printers or settings is no longer lost when the other saves.

Version 215 · 29 October 2026

  • The Log Viewer has a Commands tab listing what the system was asked to do, what came of it and the readings it took, filterable to follow one part of the system (the volume, the battery) in order.
  • The volume in the tray now follows changes made outside NoGaOS, and the volume panels open without a pause.

Version 214 · 28 October 2026

  • The system's name is spelt NoGaOS everywhere: the screens, the help and the website that still said "NoGa OS" now agree
  • The System Monitor's Processes tab tells whose each thread is from facts an app cannot fake (how it was made, its class, its group, the code it runs), with the deciding fact in the row's tooltip; apps can no longer rename a thread or change its priority.

Version 212 · 28 October 2026

  • For app makers: the names apps use for permissions, capabilities, categories and other shared constants are now spelled like Capability.FileSystem instead of Capability.FILE_SYSTEM, so apps built against an earlier version must be rebuilt; app manifests and saved files are unchanged
  • Worksheets: a word search never hides a word backwards; the information pages read themselves aloud; a View menu lets a kid choose the font and the letters and switch the reading off; a puzzle never starts with a piece already in place; the sentences the voice says after an answer are recorded in the editor's Recordings tab

Version 211 · 27 October 2026

  • System Monitor: a new Processes tab shows what NoGa OS and each app are running, the jobs NoGa OS does by itself with when each last ran, its threads with who owns them, and the programs it started on the computer; Ctrl+Alt+Del and Ctrl+Shift+Esc open the monitor on its Apps tab
  • Kiosk: when the desktop stops responding, a screen appears after about ten seconds to restart NoGa OS or turn the computer off, and the event shows in the audit trail; run the kiosk installer again to get it
  • Logging in and out is quicker, the login screen no longer reads every message to show who has new mail, and a profiler recording now survives closing the System Monitor and logging out

Version 210 · 26 October 2026

  • Installed apps can no longer read the computer's system properties, such as the home folder or the operating system name; the sandbox refuses them at install and while running
  • Media Player and Worksheets: a VLC installed only for the current user on Windows or macOS is no longer found, so install VLC for all users
