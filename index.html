NoGa OS

NoGa OS is a virtual operating system for kids: a complete desktop with its own windows, files and apps, running as a single Java program on any computer. It helps kids learn real computer basics in a controlled space: mouse, keyboard, windows, files, and simple educational/play apps. It is intentionally not a real operating system: the host does the low-level work, so all the effort goes into what a kid actually sees and touches. And it is a gateway rather than a destination: a kid outgrows it in a few years and moves on to Windows, macOS or Linux, so NoGa OS keeps to the habits those desktops share, made bigger, fewer and plainer, instead of inventing its own.

Running it

Install Java 17 or newer, then run the downloaded file:

java -jar nogaos-157.jar

The first start asks you to create an account. Video and audio playback need VLC installed on the computer; nothing else does. On a Raspberry Pi it can be set to start on boot with no Linux desktop reachable behind it.

Status

This is a personal project, written for my own children and shared in case it is useful to anyone else. It is early and it has rough edges. If you try it, bug reports and comments are welcome.

  • The right-click "New" menu only offers files a kid can start from scratch (a text file, a WordPad document, a drawing), no longer videos or settings files, and names each by what it is with its icon ("Text file (.txt)") rather than by the app; the App Manager's file types carry the same names
  • The right-click "Open with" submenu only appears when there is a real choice, not for a file whose one app is the one a double-click already opens
