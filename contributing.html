Contributing

NoGaOS is licensed under MIT, lives in GitHub, but the repository is private at this right moment. There are two reasons for that: the more mechanical one is that this project started purely as a personal private project, and I committed some photos that exist today in the git history, so before making it public I need to do some cleanup.

The second reason is that now, with AI, I fear an open repo would welcome too many PRs, which would add noise and open new security risks. As such, development is closed, and contributions are very much welcome in the form of feedback, not code. If you disagree with this approach, please let me know and I'll be happy to discuss a different setup.

Support

You can write me at celtric@gmail.com and I'll be happy to help you with NoGaOS. You can also create an issue in https://github.com/celtric/nogaos-site/issues.
