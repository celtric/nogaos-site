- Shut Down and Restart now really switch off or restart a Debian computer running NoGa OS as its only desktop, instead of NoGa OS coming straight back
- Wi-Fi from inside NoGa OS: a new Control Panel applet for administrators shows the networks in range, joins one with its password and forgets it again (on Linux computers that use NetworkManager, which is what a computer running only NoGa OS needs), and a new icon next to the clock shows whether the computer is connected and to which Wi-Fi
- Closing a window no longer throws work away without warning: Paint asks whether to save an unsaved drawing instead of saving it by itself under a made-up name, and Jigsaw, Solitaire and Mahjong ask before leaving a game you are in the middle of
- The mouse pointer no longer stays on top of the screen saver
