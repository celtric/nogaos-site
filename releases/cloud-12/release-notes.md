NoGaOS Cloud provider 12.

- `nogaos-cloud-12.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-12-userpool.yaml`, `nogaos-cloud-12-data.yaml`, `nogaos-cloud-12.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.
