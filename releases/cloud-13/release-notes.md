NoGaOS Cloud provider 13.

- `nogaos-cloud-13.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-13-userpool.yaml`, `nogaos-cloud-13-data.yaml`, `nogaos-cloud-13.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
