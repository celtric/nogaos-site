NoGaOS Cloud provider 6.

- `nogaos-cloud-6.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-6-userpool.yaml`, `nogaos-cloud-6-data.yaml`, `nogaos-cloud-6.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
