NoGaOS Cloud provider 4.

- `nogaos-cloud-4.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-4-userpool.yaml`, `nogaos-cloud-4-data.yaml`, `nogaos-cloud-4.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
