NoGaOS Cloud provider 16.

- `nogaos-cloud-16.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-16-userpool.yaml`, `nogaos-cloud-16-data.yaml`, `nogaos-cloud-16.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
