NoGaOS Cloud provider 10.

- `nogaos-cloud-10.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-10-userpool.yaml`, `nogaos-cloud-10-data.yaml`, `nogaos-cloud-10.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
