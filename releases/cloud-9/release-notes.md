NoGaOS Cloud provider 9.

- `nogaos-cloud-9.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-9-userpool.yaml`, `nogaos-cloud-9-data.yaml`, `nogaos-cloud-9.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
