NoGaOS Cloud provider 5.

- `nogaos-cloud-5.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-5-userpool.yaml`, `nogaos-cloud-5-data.yaml`, `nogaos-cloud-5.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
