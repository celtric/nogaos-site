NoGaOS Cloud provider 1.

- `nogaos-cloud-1.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-1-userpool.yaml`, `nogaos-cloud-1-data.yaml`, `nogaos-cloud-1.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
