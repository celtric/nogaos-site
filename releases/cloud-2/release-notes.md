NoGaOS Cloud provider 2.

- `nogaos-cloud-2.jar`: the server, for Lambda and for `java -jar` on any machine.
- `nogaos-cloud-2-userpool.yaml`, `nogaos-cloud-2-data.yaml`, `nogaos-cloud-2.yaml`: the CloudFormation templates that run it on AWS, launched in that order.
- `protocol.md`: the protocol it speaks.

Setup: see `cloud/README.md` in the NoGaOS repository.
