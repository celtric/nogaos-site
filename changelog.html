What changed in each recent release of NoGaOS, newest first. The home page always offers the latest one.

Changelog

Version 254 · 14 November 2026

  • Internet Browser: a page no longer shows two scrollbars, its own beside the browser's, when it loaded faster than the browser's scrollbar could take over.
  • In Catalan, progress and status lines now read the way apps talk (Baixant..., Cercant xarxes..., Connexió perduda) instead of the report-like S'està baixant or S'ha perdut.

Version 253 · 13 November 2026

  • Every app catalog is now added after the same warning, whoever publishes it: NoGaOS names no store as its own, its author's experimental apps included.

Version 252 · 13 November 2026

  • Apps from catalogs are built against this release anew: an app built for an earlier release stops opening until its catalog publishes the rebuilt version, which a computer with automatic updates fetches within the hour.

Version 251 · 13 November 2026

  • The tray's panels for serial ports, USB devices, programs and the internet show one line per app, its icon, name, data rate and the last minute's graph, under a title that fits.
  • Media Player: the progress bar draws the sound of a WAV, AIFF or AU file played from where it lives, where it stayed flat.

Version 250 · 12 November 2026

  • For app developers: each release now publishes the desktop and its test kit beside the API, in test scope, so an app written outside NoGaOS can run the same booted-desktop screenshot tests the bundled apps have; apps/README.md has the recipe.
  • Lighter on a Raspberry Pi. While nobody is at the desktop the network and system figures are read far less often and the volume not at all; the taskbar clock ticks once a minute; a wobble in the Wi-Fi signal no longer makes My Computer and the tray redraw; a desktop background is prepared off the screen thread, once, at the screen's size and the right way up, so a phone photo stands upright and takes a fraction of the memory it did; installing an app from a catalog no longer freezes the desktop; and the distribution dropped a 5 MB graphics library the browser never used, so it unpacks nothing at boot.
  • Every download is in the audit trail. Voices, the video tool and pictogram catalogs now appear as internet requests like app installs and updates already did, and an automatic update no longer holds the whole new version in memory while it checks it.
  • Smaller changes: the Open and Save dialogs show the same padlocks and custom folder icons as the Explorer; a managed policy can be revised indefinitely without its followers stopping, since only the last ten revisions keep their settings; the session window's log records traffic only while it is shown; a long value on a printer's or a computer's properties sheet wraps instead of being cut; the icon picker offers the icons in C:\Icons only. For app developers: a handful of API members nothing called were removed (InternetAccess.probe, FsPath.fromDisplayPath and the deprecated network names, Apps.setClipboard and fileContextMenu, Pictograms.ensureInstalled and isInstalled, AppStorage.setPrivate and isPrivate, WebView.setOnZoomChange and showDevTools), and Html.escape, Documents.onChange and RubberBand joined the API.

Version 249 · 11 November 2026

  • Apps can reach more of what is plugged in, when an administrator says so. An app can ask to run programs already installed on the computer, each written out as an exact command line that an administrator approves in Applications and that stops being approved if an update changes it; and to talk to USB HID devices such as a thermometer or a game controller, never a keyboard, a mouse or a touch screen. The audit trail records each program and each device, and now says how long a program, a device or a serial port was in use and how much data moved.
  • The tray shows which apps are using what. An icon appears for serial ports, USB devices, programs and the internet from the moment an open app first uses one until that app is closed; clicking it lists the apps and how busy each has been over the last minute.
  • Smaller changes: Applications now lists every installed app, also one a catalog does not offer or whose catalog was taken off the list (under Other apps), so it can be seen, given or denied permissions and removed; a catalog's tab no longer shows its address for a moment before its name; screen brightness is set from the Display applet and the laptop's keys, no longer from the battery's panel in the tray; the volume and brightness sliders lost the sunken box around them.

Version 248 · 11 November 2026

  • The camera is off until an administrator allows it, in the Camera applet, and that includes computers that already had NoGaOS: after this update a local-network session shows no picture until someone allows the camera there. Once allowed, each session asks the person at the computer whether the other side may see them; saying no keeps the session going without a picture, and View → Turn camera on asks again. The audit trail records the setting, each answer and each use turned away.
  • Screen brightness on a laptop: a slider in the battery's flyout and on a new Screen tab of the Display applet, which never lets the screen go black.
  • A laptop's volume, brightness and Wi-Fi keys work on a Linux kiosk, and the Keyboard applet's new Special keys tab lets an administrator give each action another key.

Version 247 · 11 November 2026

  • Devices on a serial port. An administrator can let an app read a device plugged into the computer, such as a GPS receiver, a micro:bit or an Arduino, with a new permission in Applications; each time an app opens or closes one is in the audit trail, never what the device said. On Linux only, and the kiosk installer prepares the computer for it. A new Location applet in the Control Panel explains that NoGaOS has no location service and why, and lists the apps that may read a plugged-in device.
  • Fixes: an app from outside NoGaOS that customises a text box or a tree no longer crashes when its window opens.

Version 246 · 10 November 2026

  • Every version of every file is kept. The computer's history records each save, move, rename and deletion on a user's drive or the Shared drive the moment it happens, keeping the file's bytes once however many saves share them and sharing the current version's bytes with the file itself where the disk allows, so a drawing deleted and gone from the Recycle Bin is still there and keeping history costs room only for what changed; a pass a minute after boot and every six hours picks up anything written another way. It replaces the git snapshots taken every five minutes, which missed what came and went between two of them and rescanned the whole drive each time; the old snapshot folder stays, readable with git, until an administrator removes it from Disk Cleanup. An administrator can Erase from history one file for good, with a reason, from the explorer's right-click.
  • What takes space…, on the storage sheet and on a drive's or folder's right-click, shows what fills it as a list and a treemap, coloured by kind; administrators also see NoGaOS's own files and the file history, and can erase a file or a folder's worth of history from there. The storage sheet shows the file history as a line of its own.
  • Backup is a new Control Panel applet: the history is copied every hour to a network folder of your choice, each computer under its own folder, resumable, with Back up now and Verify. The copies are plain files, not encrypted, and the applet says so.
  • Fixes: photos from a phone show upright in thumbnails and the picture viewer; the identity file's password takes longer to guess; the network discovery no longer resets itself whenever the Wi-Fi signal moves.

Version 245 · 9 November 2026

  • External components, a new Control Panel applet for everything NoGaOS downloads after it is installed: the browser engine, the ARASAAC pictograms, the speech engine and its voices, and the camera tool on Windows, each a row with its size, ticked to install and unticked to remove, with the space it needs and has, a description and Details… for the pictograms' languages and the voices. It replaces the ARASAAC applet, the first-run setup offers the same list, the Camera applet and the Voices tab point to it, and the browser engine can be removed at last. Removals are in the audit trail.
  • Managed computers: a History tab shows every time the policy was applied on this computer, part by part, with the value before and after or why it failed, and which apps were turned on, off or installed; the release a policy names is now the one to run, older or newer, never below the point where a release changed how files are stored; and the Updates applet lists the Previous versions kept on the computer with a Go back for each. The Settings menu of the Start menu is the Control Panel plus the applets you pin there from the Control Panel's right-click, Printers to begin with; the Neighbours tab lists this computer too.
  • Fixes: system sounds no longer keep audio lines open for the whole session, which cost an idle laptop a twentieth of a core and kept the sound card awake; logging in no longer freezes the screen while icons decode, and opening a file from a network folder no longer freezes it while the share answers; the Log Viewer reads on a dark background with each level in its own colour and stays where you scrolled while new lines arrive; the battery tray panel is the Power applet's battery tab, live; the volume panel has − and + beside its slider; progress bars fill their height; the Policy Editor's internet tab lines up; a browser shortcut opened on a cold start lands on its page, not the home page.
